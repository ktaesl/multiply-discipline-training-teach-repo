# Репозиторий дисциплины

## Информация о дисциплине

- **Дисциплина:** Разработка мобильных приложений
- **Курс:** 2 курс
- **Учебный год:** 2026–2027

## Цель репозитория

Организовать единое пространство для хранения и систематизации учебных материалов и результатов работы студентов в течение учебного года.

## Структура репозитория

```text
repository/
├── README.md
├── homeworks/
├── practices/
├── projects/
├── kr_works/
├── class_work/
└── materials/
```

### Назначение папок
### README.md

Основной файл репозитория.

Содержит:

- информацию о репозитории;
- описание структуры;
- правила работы с файлами и папками;
- общую информацию о дисциплине.

### homeworks/

Папка для домашних заданий.

Здесь размещаются задания, которые выполняются студентами самостоятельно вне учебного занятия.

### practices/

Папка для практических работ.

Здесь размещаются задания и результаты выполнения практических работ, выполняемых в рамках учебных занятий.

### projects/

Папка для проектных работ.

Здесь размещаются индивидуальные и групповые проекты студентов, а также связанные с ними материалы.

### kr_works/

Папка для контрольных работ.

Здесь размещаются контрольные работы, выполняемые в рамках дисциплины для проверки знаний и навыков студентов.

### class_work/

Папка для классных работ.

Здесь размещаются задания и результаты работ, выполняемых непосредственно во время учебного занятия.

### materials/

Папка для учебных материалов.

Здесь размещаются лекции, презентации, методические материалы, примеры, инструкции и другие материалы, необходимые для изучения дисциплины.

## Правила размещения файлов

Каждый файл необходимо размещать в соответствующей папке в зависимости от типа работы.

Перед добавлением файла необходимо проверить:

- правильность выбранной папки;
- название файла;
- формат файла;
- отсутствие лишних или дублирующихся файлов.

## Правила именования файлов

Для всех файлов используется единый и понятный принцип именования.

### Основные требования

- использовать **латинские буквы**;
- использовать **цифры** при необходимости;
- использовать символ `_` для разделения слов;
- не использовать пробелы;
- не использовать специальные символы;
- название должно кратко отражать содержание файла;
- не использовать названия `new`, `test`, `работа`, `файл` без дополнительного описания;
- не добавлять `final`, `final2`, `final_final`, `новый`, `исправленный` и подобные обозначения для разных версий одного файла.

### Рекомендуемый формат

```text
тип_работы_номер.расширение
```

Примеры:

```text
homework_variables.py
practice_dictionary.py
practice_check.py
class_work_functions.py
lecture_python_functions.pdf
```

## Порядок сдачи работ

После выполнения задания студент должен самостоятельно проверить работу и разместить её в соответствующей папке репозитория.
Работа должна быть закончена не более чем через 7 дней после дедлайна. Статус работы должен быть в README файле папки непосредственно работы.
Пример:
| файл | статус |
|------|--------|
| name.py| в работе |


### Порядок действий

1. **Выполнить задание** в соответствии с требованиями.
2. **Проверить работу** и убедиться, что она выполнена корректно.
3. **Проверить название файла** в соответствии с правилами именования.
4. **Разместить файл** в соответствующей папке репозитория.
5. **Проверить содержимое репозитория** после добавления файла.
6. **Сдать ссылку на репозиторий или работу** способом, указанным преподавателем.

### Перед сдачей необходимо проверить

- работа выполнена полностью;
- файл находится в правильной папке;
- название файла соответствует правилам;
- файл имеет необходимое расширение;
- программа запускается без ошибок, если работа предполагает программный код;
- в репозитории отсутствуют лишние файлы и дубликаты.

Если работа была исправлена после проверки, необходимо обновить существующий файл в репозитории.

## Версии файлов

Не рекомендуется создавать несколько копий одного файла для хранения разных версий.

Не следует использовать названия:

```text
practice_final.py
practice_final2.py
practice_final_final.py
practice_new.py
```

При исправлении необходимо обновить существующий файл.

## Назначение репозитория

Репозиторий используется на протяжении учебного года для хранения учебных материалов и результатов выполнения заданий по дисциплине **«Разработка мобильных приложений»**.

Структура репозитория может дополняться при необходимости в зависимости от содержания дисциплины и формата учебной работы.
