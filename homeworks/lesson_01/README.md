# Домашнее задание к занятию 1
## Повторение Python

Репозиторий с заданиями для повторения языка программирования **Python**.

Материал предназначен для студентов **2 курса колледжа**, которые изучали Python на 1 курсе и возвращаются к работе с языком после перерыва.

### Цель

Восстановить и закрепить знания основных конструкций Python, полученные на 1 курсе, а также подготовить базу для дальнейшего изучения программирования.

### Что повторяется

В заданиях используются следующие темы:

- переменные и типы данных;
- ввод и вывод данных;
- арифметические операции;
- условные конструкции `if`, `elif`, `else`;
- циклы `for` и `while`;
- работа со строками;
- списки;
- словари;
- функции;
- модули;
- обработка пользовательского ввода;
- работа с файлами;
- создание консольных программ.

### Структура заданий

Задания расположены по принципу постепенного усложнения.

#### Базовый уровень

Задания **1–9**:

- переменные;
- арифметические операции;
- условия;
- циклы;
- строки.

#### Работа со списками

Задания **10–13**:

- обработка списков;
- поиск элементов;
- фильтрация данных;
- удаление повторяющихся элементов.

#### Функции

Задания **14–15**:

- создание функций;
- параметры функций;
- возвращаемые значения;
- использование функций для обработки данных.

#### Словари

Задания **16–18**:

- создание словарей;
- добавление и изменение данных;
- поиск информации;
- простая авторизация.

#### Закрепление

Задания **19–25**:

- работа с модулем `random`;
- меню программы;
- обработка нескольких значений;
- анализ текста;
- работа с данными студентов;
- конвертация валют.

#### Итоговое задание

**Задание 26. «Мини-система для студентов»**

Итоговое задание объединяет основные темы, изученные ранее.

В программе необходимо реализовать:

- добавление студентов;
- просмотр списка студентов;
- поиск;
- изменение данных;
- удаление;
- поиск лучшего студента;
- расчёт среднего балла;
- выход из программы.

Дополнительно можно реализовать сохранение данных в файл.

### Рекомендуемый порядок выполнения

Рекомендуется выполнять задания последовательно:

```text
1–9     → базовые конструкции
10–13   → списки
14–15   → функции
16–18   → словари
19–25   → закрепление
26      → итоговое задание
```

Не рекомендуется сразу переходить к итоговому заданию. Сначала необходимо повторить отдельные конструкции Python и только после этого объединять их в одну программу.

### Требования

Для выполнения заданий потребуется:

- Python 3;
- среда разработки или редактор кода;
- базовые знания Python, полученные на 1 курсе.

### Результат выполнения

Для каждого задания необходимо создать отдельный файл с программой.

Например:

```text
task_01.py
task_02.py
task_03.py
...
task_26.py
```

Для итогового задания рекомендуется создать отдельную папку:

```text
final_project/
├── main.py
└── ...
```

### Правила оформления кода

При выполнении заданий рекомендуется:

- давать переменным понятные имена;
- соблюдать отступы;
- использовать функции при необходимости;
- не дублировать одинаковый код;
- добавлять комментарии к сложным участкам программы;
- проверять программу на разных вариантах входных данных.
