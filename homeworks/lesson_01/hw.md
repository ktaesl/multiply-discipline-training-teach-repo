# Задачи для повторения Python

## Для студентов 2 курса

Задания предназначены для повторения основных возможностей языка Python, изученных на 1 курсе.

---

## Задание 1. Переменные и арифметические операции

Пользователь вводит стоимость товара и количество товара.

Программа должна вывести:

- общую стоимость;
- стоимость со скидкой 10%;
- размер скидки.

---

## Задание 2. Условия

Пользователь вводит число.

Определить:

- положительное оно, отрицательное или равно нулю;
- является ли оно чётным или нечётным.

---

## Задание 3. Максимальное число

Пользователь вводит три числа.

Вывести наибольшее из них.

**Дополнительно:** решить задачу без использования функции `max()`.

---

## Задание 4. Оценка студента

Пользователь вводит количество набранных баллов от 0 до 100.

Вывести результат:

- `90–100` — «Отлично»;
- `75–89` — «Хорошо»;
- `60–74` — «Удовлетворительно»;
- меньше `60` — «Неудовлетворительно».

Предусмотреть проверку некорректного ввода.

---

## Задание 5. Числа от 1 до 100

Вывести все числа от `1` до `100`, которые делятся одновременно на `3` и `5`.

---

## Задание 6. Сумма чисел

Пользователь вводит число `N`.

Найти сумму всех чисел от `1` до `N`.

Пример:

```text
Введите N: 10
Сумма: 55
```

---

## Задание 7. Таблица умножения

Пользователь вводит число.

Вывести таблицу умножения для этого числа от `1` до `10`.

Пример:

```text
Введите число: 7

7 * 1 = 7
7 * 2 = 14
7 * 3 = 21
...
7 * 10 = 70
```

---

## Задание 8. Работа со строкой

Пользователь вводит строку.

Программа должна определить:

- количество символов;
- количество пробелов;
- количество букв `а`;
- начинается ли строка с заглавной буквы.

---

## Задание 9. Палиндром

Пользователь вводит слово.

Определить, читается ли оно одинаково слева направо и справа налево.

Примеры:

```text
шалаш → да
привет → нет
```

---

## Задание 10. Список оценок

Дан список оценок студентов:

```python
grades = [5, 4, 3, 5, 2, 4, 5, 3, 4]
```

Найти:

- среднюю оценку;
- максимальную оценку;
- минимальную оценку;

- количество двоек.

## Задание 11. Чётные числа

Пользователь вводит 10 чисел.

Создать новый список, в который попадут только чётные числа из исходного списка.

## Задание 12. Удаление повторов

Дан список:

```python
numbers = [3, 5, 3, 7, 5, 8, 9, 7, 3]
```

Создать новый список, в котором каждое число встречается только один раз.

**Дополнительно:** сохранить первоначальный порядок элементов.

## Задание 13. Поиск элемента

Дан список имён:

```python
names = ["Анна", "Иван", "Мария", "Дмитрий", "Ольга"]
```

Пользователь вводит имя.

Программа должна сообщить, есть ли такое имя в списке.

## Задание 14. Функция для проверки числа

Написать функцию `is_even(number)`, которая принимает число и возвращает:

```python
True
```

если число чётное, и:

```python
False
```

если число нечётное.

## Задание 15. Функция для определения оценки

Написать функцию `get_grade(score)`, которая получает количество баллов и возвращает текстовую оценку.

Например:

```python
get_grade(95)
```

Результат:

```text
Отлично
```

## Задание 16. Информация о студенте

Создать словарь:

```python
student = {
    "name": "Иван",
    "age": 18,
    "group": "ИС-21",
    "average": 4.5
}
```

Вывести информацию о студенте в удобном виде.

Затем:

1. изменить средний балл;
2. добавить новое поле `city`;
3. вывести обновлённую информацию.

## Задание 17. Подсчёт слов

Пользователь вводит предложение.

С помощью словаря подсчитать, сколько раз встречается каждое слово.

Пример:

```text
Введите текст: кот пес кот дом
```

Результат:

```text
кот: 2
пес: 1
дом: 1
```

---

## Задание 18. Мини-авторизация

Создать словарь с несколькими пользователями:

```python
users = {
    "admin": "1234",
    "student": "qwerty",
    "user": "1111"
}
```

Пользователь вводит логин и пароль.

Программа должна определить, правильные ли данные.

### Дополнительно

## Задание 19. Угадай число

Программа загадывает случайное число от `1` до `100`.

Пользователь пытается его угадать.

После каждой попытки программа должна сообщать:

- «Загаданное число больше»;
- «Загаданное число меньше»;
- «Вы угадали!».

Использовать модуль `random`.

### Дополнительно

Подсчитать количество попыток пользователя.

## Задание 20. Мини-проект «Учёт товаров»

Создать программу для работы со списком товаров.

Каждый товар должен содержать:

- название;
- цену;
- количество.

Программа должна позволять:

1. вывести все товары;
2. добавить товар;
3. найти товар по названию;
4. посчитать общую стоимость всех товаров;
5. найти самый дорогой товар.

### Дополнительно

Добавить возможность удалить товар из списка.
