# Домашнее задание

## Тема

**Развитие информационной системы кафе: хранение заказа в словаре**

## Продолжение проекта

В практической работе заказ хранился в виде списка.

Теперь необходимо изменить структуру программы: **заказ должен храниться в словаре**.

Для выполнения задания используйте материал из файла `theory.md`.

## Задание

Доработайте существующую программу информационной системы кафе.

Необходимо заменить список заказа:

```python
order = []
```

на словарь:

```python
order = {}
```

Теперь словарь должен хранить информацию по принципу:

```text
название позиции → количество
```

Например:

```python
order = {
    "Бургер": 2,
    "Кола": 1
}
```

Это означает, что пользователь заказал два бургера и одну колу.

---

## 1. Добавление позиции в заказ

При выборе пользователем позиции необходимо проверить, есть ли она уже в словаре `order`.

Если позиции ещё нет, добавить её с количеством `1`.

Например:

```python
order["Бургер"] = 1
```

---

## 2. Повторный выбор позиции

Если пользователь выбирает позицию, которая уже находится в заказе, необходимо увеличить её количество на `1`.

Например:

```python
order["Бургер"] += 1
```

В результате нескольких одинаковых выборов:

```text
Бургер
Кола
Бургер
Бургер
```

должен получиться словарь:

```python
order = {
    "Бургер": 3,
    "Кола": 1
}
```

---

## 3. Обработка заказа

Используйте цикл `for` и метод `.items()` для обработки словаря заказа:

```python
for item, count in order.items():
    ...
```

Для каждой позиции необходимо получить:

- название;
- количество;
- стоимость одной позиции из словаря `menu`;
- стоимость всех единиц этой позиции.

Стоимость позиции рассчитывается по формуле:

```text
цена × количество
```

---

## 4. Формирование чека

Измените чек так, чтобы одинаковые позиции не выводились несколько раз.

Например, вместо:

```text
Бургер — 250 руб.
Бургер — 250 руб.
Бургер — 250 руб.
Кола — 100 руб.
```

должно выводиться:

```text
Чек
--------------------
Бургер — 3 шт. × 250 руб. = 750 руб.
Кола — 1 шт. × 100 руб. = 100 руб.
--------------------
Итого: 850 руб.
```

Расчёты должны выполняться программой автоматически.

---

## 5. Подсчёт общего количества товаров

Определите общее количество заказанных единиц.

Например:

```python
order = {
    "Бургер": 3,
    "Кола": 1
}
```

Общее количество товаров:

```text
4
```

Для подсчёта необходимо использовать цикл и количество каждой позиции.

---

## 6. Скидка

Сохраните систему скидок из практического задания:

- от 1000 рублей — скидка 10%;
- от 500 до 999 рублей — скидка 5%;
- менее 500 рублей — скидки нет.

Скидка должна рассчитываться от общей стоимости всего заказа.

---

## 7. Проверка заказа

Программа должна продолжать проверять, существует ли введённая пользователем позиция в меню.

Если пользователь вводит неизвестную позицию:

```text
Такой позиции нет в меню.
Выберите позицию из доступного меню.
```

Такая позиция не должна добавляться в `order`.

---

## Требования к программе

В программе должны использоваться:

- словарь `menu`;
- словарь `order`;
- `if / elif / else`;
- цикл `for`;
- оператор `in`;
- метод `.items()`;
- арифметические операции;
- проверка существования позиции в меню.
