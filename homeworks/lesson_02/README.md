# Домашнее задание 2

## Тема

**Развитие информационной системы кафе: хранение заказа в словаре**

## Цель задания

Продолжить разработку информационной системы кафе и изменить способ хранения заказа.

В предыдущих заданиях заказ формировался с помощью списка. На этом этапе необходимо использовать **словарь**, который будет хранить название позиции и количество заказанных единиц.

## Что необходимо сделать

Необходимо доработать программу кафе, созданную на предыдущих занятиях.

В результате программа должна:

- хранить меню в словаре `menu`;
- хранить заказ в словаре `order`;
- учитывать количество каждой заказанной позиции;
- рассчитывать стоимость каждой позиции;
- рассчитывать общую стоимость заказа;
- рассчитывать скидку;
- формировать итоговый чек.

### Структура заказа

Заказ должен храниться по принципу:

```text
название позиции → количество
```

Например:

```python
order = {
    "Бургер": 3,
    "Кола": 1
}
```

Это означает, что в заказе находятся три бургера и одна кола.

## Результат выполнения

После выполнения задания должна получиться следующая версия информационной системы кафе:

```text
Меню
  ↓
Выбор позиции
  ↓
Словарь заказа
  ↓
Подсчёт количества
  ↓
Расчёт стоимости
  ↓
Скидка
  ↓
Итоговый чек
```

Одинаковые позиции должны объединяться в заказе и отображаться с указанием количества.

Например:

```text
Чек
--------------------
Бургер — 3 шт. × 250 руб. = 750 руб.
Кола — 1 шт. × 100 руб. = 100 руб.
--------------------
Итого: 850 руб.
```
