# Теория

## Тема

**Словари в Python**

## 1. Что такое словарь

**Словарь (`dict`)** — это структура данных, которая хранит информацию в виде пар:

```text
ключ → значение
```

В отличие от списка, где элементы имеют порядковые номера, в словаре значение находится по ключу.

Пример:

```python
menu = {
    "Бургер": 250,
    "Картофель фри": 150,
    "Кола": 100
}
```

Здесь:

- `"Бургер"` — ключ;
- `250` — значение;
- `"Картофель фри"` — ключ;
- `150` — значение.

В нашем проекте словарь `menu` уже используется для хранения меню кафе.

---

## 2. Создание словаря

Пустой словарь создаётся с помощью `{}`:

```python
order = {}
```

После этого в него можно добавлять данные.

Например:

```python
order = {
    "Бургер": 2,
    "Кола": 1
}
```

Такой словарь можно использовать для хранения заказа.

Здесь:

```text
Бургер → 2
Кола → 1
```

То есть пользователь заказал два бургера и одну колу.

---

## 3. Получение значения по ключу

Чтобы получить значение из словаря, указывается ключ:

```python
menu = {
    "Бургер": 250,
    "Кола": 100
}

print(menu["Бургер"])
```

Результат:

```text
250
```

В нашем проекте это позволяет узнать стоимость выбранной позиции.

---

## 4. Добавление элемента в словарь

Чтобы добавить новую пару `ключ → значение`, используется обращение по ключу:

```python
order = {}

order["Бургер"] = 1
order["Кола"] = 1
```

Теперь словарь содержит:

```python
{
    "Бургер": 1,
    "Кола": 1
}
```

---

## 5. Изменение значения

Если такой ключ уже существует, присваивание изменит его значение:

```python
order = {
    "Бургер": 1
}

order["Бургер"] = 2
```

Теперь:

```python
{
    "Бургер": 2
}
```

Это особенно важно для нашего проекта.

Если пользователь второй раз выбирает бургер, нам не нужно создавать ещё один ключ `"Бургер"`. Нужно увеличить его количество.

---

## 6. Проверка наличия ключа

Для проверки наличия элемента в словаре можно использовать оператор `in`:

```python
if "Бургер" in order:
    print("Бургер уже есть в заказе")
```

Это позволяет определить, был ли товар уже добавлен в заказ.

---

## 7. Увеличение количества товара

Рассмотрим ситуацию:

```python
order = {
    "Бургер": 1
}
```

Пользователь снова выбирает бургер.

Можно увеличить количество:

```python
order["Бургер"] = order["Бургер"] + 1
```

После этого:

```python
{
    "Бургер": 2
}
```

Сокращённая запись:

```python
order["Бургер"] += 1
```

Результат будет таким же.

---

## 8. Добавление новой позиции или увеличение количества

При формировании заказа нам необходимо учитывать два случая:

### Позиции ещё нет в заказе

```python
if item not in order:
    order[item] = 1
```

### Позиция уже есть

```python
else:
    order[item] += 1
```

Таким образом, один и тот же товар не создаётся в словаре несколько раз.

Например, пользователь выбирает:

```text
Бургер
Кола
Бургер
Бургер
```

В результате получится:

```python
order = {
    "Бургер": 3,
    "Кола": 1
}
```

---

## 9. Перебор словаря с помощью `for`

Словарь можно обрабатывать с помощью цикла `for`.

Если нужны только ключи:

```python
for item in order:
    print(item)
```

Результат:

```text
Бургер
Кола
```

Если нужны одновременно ключ и значение, используется метод `.items()`:

```python
for item, count in order.items():
    print(item, count)
```

Результат:

```text
Бургер 3
Кола 1
```

В нашем проекте это позволит вывести в чек название позиции и её количество.

---

## 10. Получение стоимости и количества

В нашем проекте используются два словаря:

```python
menu = {
    "Бургер": 250,
    "Кола": 100
}

order = {
    "Бургер": 3,
    "Кола": 1
}
```

Из `menu` мы получаем стоимость:

```python
menu[item]
```

Из `order` получаем количество:

```python
order[item]
```

Например:

```python
item = "Бургер"

price = menu[item]
count = order[item]
```

Получим:

```text
price = 250
count = 3
```

Стоимость этой позиции в заказе можно рассчитать как:

```python
price * count
```

То есть:

```text
250 × 3 = 750
```

## 11. Словарь меню и словарь заказа

В нашем проекте словари выполняют разные задачи.

### Меню

```python
menu = {
    "Бургер": 250,
    "Кола": 100,
    "Картофель фри": 150
}
```

Хранит:

```text
позиция → цена
```

### Заказ

```python
order = {
    "Бургер": 2,
    "Кола": 1
}
```

Хранит:

```text
позиция → количество
```

Таким образом, программа разделяет две разные характеристики:

```text
menu
позиция → цена

order
позиция → количество
```

Это делает структуру программы более удобной для дальнейшего развития.

---

## 12. Пример обработки заказа

Допустим, у нас есть:

```python
menu = {
    "Бургер": 250,
    "Кола": 100,
    "Картофель фри": 150
}

order = {
    "Бургер": 2,
    "Кола": 1
}
```

Можно пройти по заказу:

```python
for item, count in order.items():
    price = menu[item]
    total = price * count

    print(item, count, total)
```

Программа обработает каждую позицию заказа отдельно.

---

## 13. Что нужно запомнить

| Операция | Пример |
|---|---|
| Создать пустой словарь | `order = {}` |
| Добавить позицию | `order["Бургер"] = 1` |
| Получить значение | `order["Бургер"]` |
| Проверить ключ | `"Бургер" in order` |
| Увеличить количество | `order["Бургер"] += 1` |
| Перебрать ключи | `for item in order:` |
| Перебрать ключи и значения | `for item, count in order.items():` |

## Главное для проекта

В следующей версии информационной системы кафе заказ будет храниться **не в списке, а в словаре**.

Было:

```python
order = ["Бургер", "Кола", "Бургер"]
```

Станет:

```python
order = {
    "Бургер": 2,
    "Кола": 1
}
```

Это позволит программе автоматически хранить количество каждой заказанной позиции и формировать более удобный чек.
