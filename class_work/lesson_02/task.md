# Практическая работа

## Тема

**Доработка программы формирования чека: условия и списки в Python**

## Цель работы

Доработать программу формирования чека из предыдущего занятия, используя **списки и условные конструкции**.

В ходе работы необходимо научиться хранить несколько выбранных пользователем позиций в списке, обрабатывать список с помощью цикла и принимать решения с помощью `if`, `elif`, `else`.

## Задание

Продолжите разработку программы формирования чека, которую вы создавали на предыдущем занятии.

В программе уже есть словарь с меню:

```python
menu = {
    "Бургер": 250,
    "Картофель фри": 150,
    "Кола": 100
}
```

Теперь необходимо добавить в программу **список заказа** и дополнительную логику с использованием условий.

---

## 1. Создание списка заказа

Создайте пустой список, в котором будут храниться названия выбранных пользователем позиций.

Например:

```python
order = []
```

Каждый раз, когда пользователь выбирает существующую позицию из меню, её название должно добавляться в список заказа.

Для добавления элемента используйте метод:

```python
append()
```

---

## 2. Формирование заказа

Пользователь должен иметь возможность выбрать несколько позиций из меню.

Программа должна:

1. показать доступное меню;
2. получить название позиции от пользователя;
3. проверить, есть ли такая позиция в меню;
4. добавить выбранную позицию в список заказа;
5. продолжать принимать позиции до завершения ввода.

Если пользователь вводит позицию, которой нет в меню, программа должна вывести сообщение об ошибке.

---

## 3. Вывод содержимого заказа

После завершения ввода выведите все выбранные позиции из списка заказа.

Для обработки списка используйте цикл `for`.

Например:

```text
Ваш заказ:
Бургер
Кола
Картофель фри
```

---

## 4. Подсчёт стоимости заказа

Используя список заказа и словарь меню, рассчитайте общую стоимость заказа.

Для этого необходимо:

- пройти по списку заказа с помощью `for`;
- получить стоимость каждой позиции из словаря;
- добавить стоимость к общей сумме.

В результате должна получиться общая стоимость всего заказа.

---

## 5. Проверка количества позиций

Используя функцию `len()`, определите количество позиций в заказе.

В зависимости от количества позиций выведите сообщение:

- если выбрана **1 позиция** — `Вы выбрали одну позицию`;
- если выбрано **2 или 3 позиции** — `Небольшой заказ`;
- если выбрано **4 и более позиций** — `Большой заказ`.

Для решения используйте:

```python
if
elif
else
```

---

## 6. Система скидок

Добавьте в программу скидку в зависимости от итоговой суммы заказа.

Используйте следующие условия:

- если сумма заказа **1000 рублей или больше** — скидка 10%;
- если сумма заказа **500 рублей или больше**, но меньше 1000 — скидка 5%;
- если сумма меньше 500 рублей — скидки нет.

Программа должна вывести:

- первоначальную сумму;
- размер скидки;
- итоговую сумму после скидки.

Например:

```text
Сумма заказа: 1200 руб.
Скидка: 10%
К оплате: 1080 руб.
```

---

## 7. Проверка наличия определённой позиции

Используя оператор `in`, проверьте, есть ли в заказе бургер.

Если бургер есть, выведите:

```text
В заказе есть бургер.
```

Если бургера нет:

```text
Бургера в заказе нет.
```

---

## 8. Итоговый чек

В конце программы сформируйте итоговый чек.

Чек должен содержать:

- заголовок;
- все выбранные позиции;
- стоимость заказа;
- количество позиций;
- информацию о скидке;
- итоговую сумму к оплате.

Пример:

```text
Чек
--------------------
Бургер — 250 руб.
Кола — 100 руб.
Бургер — 250 руб.
Картофель фри — 150 руб.
--------------------
Позиций: 4
Сумма: 750 руб.
Скидка: 5%
К оплате: 712.5 руб.
```
