## Практическое задание

В рамках занятия необходимо разработать консольную программу для анализа результатов группы.

В программе используется список оценок студентов:

```python
grades = [5, 4, 3, 5, 2, 4, 5, 3, 4, 2]
```

Программа должна:

- вывести все оценки;
- определить количество студентов;
- определить количество отличных оценок;
- определить количество неудовлетворительных оценок;
- проверить наличие двоек;
- вычислить среднюю оценку;
- определить общий результат группы в зависимости от средней оценки.

Для анализа элементов списка необходимо использовать циклы и условные конструкции.

Подробное описание задания находится в файле:

```text
practice.md
```

## Результат выполнения задания

В результате выполнения задания должна быть создана работающая консольная программа на Python, которая:

- работает со списком оценок;
- обрабатывает элементы списка;
- подсчитывает необходимые показатели;
- использует условные конструкции;
- вычисляет среднюю оценку;
- выводит результаты анализа в понятном виде.

## Критерии проверки программы

При проверке программы учитываются следующие требования:

### 1. Работа со списком

- Используется список для хранения оценок.
- Программа корректно получает элементы списка.
- Для обработки списка используется цикл.

### 2. Использование условий

- Используется `if`.
- При необходимости используются `elif` и `else`.
- Используются операторы сравнения.
- Условия корректно определяют необходимые категории оценок.

### 3. Анализ оценок

- Определяется количество студентов.
- Подсчитывается количество оценок `5`.
- Подсчитывается количество оценок `2`.
- Проверяется наличие неудовлетворительных оценок.
- Вычисляется средняя оценка.

### 4. Определение результата группы

Результат определяется по средней оценке:

- `4.5` и выше — **«Отличный результат»**;
- от `3.5` до `4.49` — **«Хороший результат»**;
- от `3.0` до `3.49` — **«Удовлетворительный результат»**;
- меньше `3.0` — **«Группе нужно повторить материал»**.

### 5. Вывод результатов

Программа должна выводить:

- количество студентов;
- количество отличных оценок;
- количество неудовлетворительных оценок;
- наличие или отсутствие двоек;
- среднюю оценку;
- итоговую характеристику группы.

### 6. Корректность работы

Программа должна запускаться без ошибок и корректно работать при различных наборах оценок.

Необходимо проверить программу как минимум на:

- списке, содержащем только положительные оценки;
- списке с несколькими двойками;
- списке, содержащем оценки разных типов;
- изменённом количестве элементов списка.

### 7. Размещение работы

- Файл размещён в папке `lesson_02/`.
- Учебные материалы находятся в соответствующей папке.
- Работа загружена в репозиторий дисциплины.
