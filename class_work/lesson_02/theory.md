# Теория

## 1. Условные конструкции

Условные конструкции позволяют программе выполнять разные действия в зависимости от значения некоторого условия.

Основная конструкция:

```python
if условие:
    действие
```

Например:

```python
age = 18

if age >= 18:
    print("Доступ разрешён")
```

Если условие `age >= 18` является истинным, программа выполнит команду `print()`.

---

## 2. `if`, `elif`, `else`

Если необходимо проверить несколько вариантов, используются `elif` и `else`.

```python
score = 75

if score >= 90:
    print("Отлично")
elif score >= 70:
    print("Хорошо")
elif score >= 50:
    print("Удовлетворительно")
else:
    print("Неудовлетворительно")
```

Python проверяет условия сверху вниз.

Если одно из условий оказывается истинным, выполняется соответствующий блок, а остальные условия пропускаются.

### `if`

Проверяет условие:

```python
if score >= 50:
    print("Зачёт")
```

### `elif`

Используется для проверки следующего условия:

```python
if score >= 90:
    print("Отлично")
elif score >= 70:
    print("Хорошо")
```

### `else`

Выполняется, если ни одно из предыдущих условий не оказалось истинным:

```python
if score >= 50:
    print("Зачёт")
else:
    print("Незачёт")
```

---

## 3. Операторы сравнения

Для создания условий используются операторы сравнения.

| Оператор | Значение | Пример |
|---|---|---|
| `==` | равно | `x == 10` |
| `!=` | не равно | `x != 10` |
| `>` | больше | `x > 10` |
| `<` | меньше | `x < 10` |
| `>=` | больше или равно | `x >= 10` |
| `<=` | меньше или равно | `x <= 10` |

Например:

```python
number = 10

if number > 0:
    print("Число положительное")
```

### Важно

`=` и `==` выполняют разные действия.

`=` используется для присваивания:

```python
number = 10
```

`==` используется для сравнения:

```python
if number == 10:
    print("Число равно 10")
```

---

## 4. Логические операторы

Логические операторы позволяют объединять несколько условий.

### `and`

Оператор `and` означает **«и»**.

Оба условия должны быть истинными.

```python
age = 20
has_ticket = True

if age >= 18 and has_ticket:
    print("Можно войти")
```

### `or`

Оператор `or` означает **«или»**.

Достаточно, чтобы истинным было хотя бы одно условие.

```python
day = "Saturday"

if day == "Saturday" or day == "Sunday":
    print("Выходной")
```

### `not`

Оператор `not` изменяет условие на противоположное.

```python
is_blocked = False

if not is_blocked:
    print("Пользователь активен")
```

# Списки

## 5. Что такое список

Список — это структура данных, которая позволяет хранить несколько значений в одной переменной.

Список создаётся с помощью квадратных скобок:

```python
numbers = [10, 20, 30, 40, 50]
```

В списке могут храниться строки:

```python
students = ["Анна", "Иван", "Мария"]
```

Также Python позволяет хранить значения разных типов:

```python
data = [10, "Python", 3.14, True]
```

Однако при решении практических задач чаще всего в одном списке хранят данные одного типа или одного назначения.

---

## 6. Индексы списка

Каждый элемент списка имеет свой индекс.

Индексация начинается с `0`.

Например:

```python
numbers = [10, 20, 30, 40, 50]
```

| Индекс | Значение |
|---:|---:|
| `0` | `10` |
| `1` | `20` |
| `2` | `30` |
| `3` | `40` |
| `4` | `50` |

Получить элемент списка можно по его индексу:

```python
print(numbers[0])
```

Результат:

```text
10
```

Можно обратиться к последнему элементу с помощью отрицательного индекса:

```python
print(numbers[-1])
```

Результат:

```text
50
```

---

## 7. Изменение элементов списка

Списки являются изменяемыми.

Это означает, что отдельный элемент списка можно заменить.

```python
numbers = [10, 20, 30]

numbers[1] = 100

print(numbers)
```

Результат:

```text
[10, 100, 30]
```

---

## 8. Количество элементов списка

Для определения количества элементов используется функция `len()`.

```python
numbers = [10, 20, 30, 40, 50]

print(len(numbers))
```

Результат:

```text
5
```

Функция `len()` особенно полезна, когда количество элементов заранее неизвестно.

Например:

```python
students = ["Анна", "Иван", "Мария"]

print("Количество студентов:", len(students))
```

Результат:

```text
Количество студентов: 3
```

---

## 9. Добавление элементов

Для добавления элемента в конец списка используется метод `append()`.

```python
numbers = [10, 20, 30]

numbers.append(40)

print(numbers)
```

Результат:

```text
[10, 20, 30, 40]
```

---

## 10. Удаление элементов

### `remove()`

Метод `remove()` удаляет элемент по его значению.

```python
numbers = [10, 20, 30]

numbers.remove(20)

print(numbers)
```

Результат:

```text
[10, 30]
```

### `pop()`

Метод `pop()` удаляет элемент по индексу.

```python
numbers = [10, 20, 30]

numbers.pop(1)

print(numbers)
```

Результат:

```text
[10, 30]
```

Если индекс не указать, `pop()` удалит последний элемент:

```python
numbers.pop()
```

---

## 11. Сортировка списка

Для сортировки элементов используется метод `sort()`.

```python
numbers = [5, 2, 8, 1, 4]

numbers.sort()

print(numbers)
```

Результат:

```text
[1, 2, 4, 5, 8]
```

Для сортировки в обратном порядке можно использовать:

```python
numbers.sort(reverse=True)
```

---

## 12. Проверка наличия элемента

С помощью оператора `in` можно проверить, содержится ли значение в списке.

```python
students = ["Анна", "Иван", "Мария"]

if "Иван" in students:
    print("Иван найден")
```

Можно проверить отсутствие элемента с помощью `not in`:

```python
if "Пётр" not in students:
    print("Пётр отсутствует")
```

Такая проверка часто используется вместе с условными конструкциями.

# Работа со списками и условиями

## 13. Перебор элементов списка

Для последовательной обработки элементов списка используется цикл `for`.

```python
numbers = [10, 20, 30, 40]

for number in numbers:
    print(number)
```

Результат:

```text
10
20
30
40
```

Переменная `number` по очереди получает значения всех элементов списка.

---

## 14. Условие внутри цикла

Условие можно использовать внутри цикла.

Например, необходимо вывести только чётные числа:

```python
numbers = [10, 15, 22, 31, 40]

for number in numbers:
    if number % 2 == 0:
        print(number)
```

Результат:

```text
10
22
40
```

Здесь программа:

1. получает очередной элемент списка;
2. проверяет его с помощью `if`;
3. определяет остаток от деления на `2`;
4. выводит число, если оно чётное.

---

## 15. Подсчёт элементов по условию

Цикл и условие можно использовать для подсчёта элементов, которые соответствуют определённому условию.

Например, необходимо посчитать количество пятёрок:

```python
grades = [5, 4, 3, 5, 2, 4, 5]

count = 0

for grade in grades:
    if grade == 5:
        count += 1

print("Количество пятёрок:", count)
```

Результат:

```text
Количество пятёрок: 3
```

Переменная `count` используется как счётчик.

Каждый раз, когда программа встречает оценку `5`, значение `count` увеличивается на единицу.

---

## 16. Подсчёт элементов с другим условием

Можно считать не только конкретное значение, но и элементы, соответствующие условию.

Например, посчитать количество положительных чисел:

```python
numbers = [-5, 10, -2, 7, 3, -1]

count = 0

for number in numbers:
    if number > 0:
        count += 1

print("Положительных чисел:", count)
```

---

## 17. Вычисление суммы элементов

Для вычисления суммы элементов списка можно использовать встроенную функцию `sum()`.

```python
numbers = [10, 20, 30, 40]

total = sum(numbers)

print("Сумма:", total)
```

Результат:

```text
Сумма: 100
```

---

## 18. Вычисление среднего значения

Чтобы получить среднее значение элементов списка, можно разделить сумму элементов на их количество.

```python
grades = [5, 4, 3, 5, 4]

average = sum(grades) / len(grades)

print("Средняя оценка:", average)
```

Результат:

```text
Средняя оценка: 4.2
```

Здесь используются сразу две функции:

```python
sum(grades)
```

получает сумму оценок, а

```python
len(grades)
```

получает количество оценок.

# Главное сочетание

## 19. Список + цикл + условие

При обработке списков часто используется следующая схема:

```python
список = [...]

for элемент in список:
    if условие:
        действие
```

Например:

```python
grades = [5, 4, 3, 5, 2, 4, 5]

for grade in grades:
    if grade == 5:
        print("Отличная оценка")
```

В этой конструкции:

- `grades` — список;
- `for` — перебирает элементы списка;
- `grade` — текущий элемент;
- `if` — проверяет условие;
- `grade == 5` — условие;
- `print()` — действие, которое выполняется при истинном условии.

Именно такую конструкцию необходимо будет использовать в практической работе.
