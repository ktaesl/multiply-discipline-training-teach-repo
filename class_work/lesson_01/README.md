## Практическое задание

В рамках занятия необходимо разработать консольную программу для формирования чека.

Программа должна содержать меню в виде словаря, где:

- ключ — название позиции (`str`);
- значение — стоимость позиции (`int`).

Пользователь выбирает позиции из меню. Ввод продолжается до команды `готово`. После завершения ввода программа выводит чек со всеми выбранными позициями и итоговой суммой заказа.

## Результат выполнения задания

В результате выполнения задания должна быть создана работающая консольная программа на Python, которая:

- принимает от пользователя выбранные позиции;
- формирует чек с выбранными позициями и их стоимостью;
- рассчитывает и выводит итоговую сумму заказа.

## Требования к размещению файла

Готовую программу необходимо разместить в папке:

```text
class_work/lesson_01/task.md
```

Файл программы должен иметь расширение `.py`.

Рекомендуемое имя файла:

```text
task.py
```

Итоговая структура:

```text
repository/
├── README.md
├── class_work/
│   └── task.py
```

После добавления файла необходимо сохранить изменения и отправить их на Github.

## Запуск программы

Для запуска программы необходимо открыть терминал в папке с файлом `task.py` и выполнить команду:

```bash
python task.py
```

Если в системе используется команда `python3`, необходимо выполнить:

```bash
python3 task.py
```

## Критерии проверки программы

При проверке программы учитываются следующие требования:

### 1. Структура данных

- Используется словарь для хранения меню.
- Названия позиций являются ключами типа `str`.
- Стоимость позиций является значением типа `int`.


### 2. Ввод данных

- Программа принимает названия позиций от пользователя.
- Программа корректно обрабатывает неизвестную позицию.

### 3. Формирование заказа

- Для каждой выбранной позиции определяется стоимость.
- Итоговая сумма рассчитывается автоматически.

### 4. Формирование чека

- Все выбранные позиции выводятся отдельными строками.
- Рядом с каждой позицией указана её стоимость.
- В конце чека выводится итоговая сумма.

### 5. Корректность работы

Программа должна запускаться без ошибок и корректно работать при:

- выборе одной позиции;
- выборе нескольких позиций;
- повторном выборе одной и той же позиции;
- вводе несуществующей позиции;
- завершении заказа командой `готово`.

### 6. Размещение работы

- Файл имеет расширение `.py`.
- Файл размещён в папке `lesson_01/`.
- Работа загружена в репозиторий дисциплины.
