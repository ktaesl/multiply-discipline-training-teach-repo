# Практическое задание

## Тема

**Создание программы для формирования чека с использованием словаря в Python**

## Задание

Необходимо разработать программу на **Python**, которая позволяет сформировать чек по заказу.

В программе должно быть реализовано **меню**, представленное в виде словаря.

### Требования к словарю

Словарь должен содержать информацию о доступных позициях меню:

- **ключ** — название позиции, тип данных `str`;
- **значение** — стоимость позиции, тип данных `int`.

Пример структуры словаря:

```python
menu = {
    "Бургер": 250,
    "Картофель фри": 150,
    "Кола": 100
}
```

### Логика работы программы

Программа должна:

1. Вывести пользователю доступные позиции меню.
2. Принимать от пользователя названия позиций, которые он хочет добавить в заказ.
3. Проверять, существует ли введённая позиция в меню.
4. Добавлять стоимость выбранной позиции к общей сумме заказа.
5. После завершения ввода вывести чек.

### Формат чека

В чеке каждая заказанная позиция должна быть выведена **отдельной строкой** вместе с её стоимостью.

В конце чека необходимо вывести **итоговую сумму заказа**.

Пример:

```text
Чек
--------------------
Бургер — 250 руб.
Кола — 100 руб.
Картофель фри — 150 руб.
--------------------
Итого: 500 руб.
```

## Дополнительное условие

Если пользователь вводит название позиции, которой нет в меню, программа должна сообщить об ошибке и предложить выбрать позицию из доступного меню. /
Один ввод - один заказ.

## Результат работы

В результате должна получиться консольная программа, которая позволяет пользователю выбрать несколько позиций из меню и получить итоговый чек с рассчитанной стоимостью заказа.

**Язык программирования:** Python.
